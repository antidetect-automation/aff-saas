# Multilogin Affiliate Handoff

## Project Goal
Build a zero-cost, highly automated affiliate growth system for the `Multilogin` niche using:
- `Telegram Bot` as the central funnel
- `Cloudflare Pages/Workers` for free utilities and landing pages
- `GitHub` and `GitHub Actions` for open-source distribution and automation

Main objective:
- Attract technical users with useful tools and content
- Route all calls to action to the Telegram bot
- Convert users naturally through workflow utility instead of spam

## Core Funnel
Primary bot:
- `https://t.me/Multilogin_Scripts_Bot`

Coupons:
- `SAAS50` = Multilogin Antidetect Browser, 50% lifetime
- `MIN50` = Multilogin Cloud Phone, 50% lifetime

Routing logic:
- Desktop multi-account, browser isolation, ads, scraping, automation -> `SAAS50`
- Android cloud workflows, app-based account management -> `MIN50`

## What Was Discussed
The strategy should focus on:
- Building evergreen assets instead of short-term spam tactics
- Solving real technical pain points first
- Using transparent sponsorship and contextual CTA
- Automating publishing, repurposing, attribution, and bot onboarding
- Avoiding mass DM, mass comments, or fake community engagement

## Recommended Distribution Engine
Main platforms:
- `GitHub` for starter kits, SDK wrappers, boilerplates, CLI tools, README-based conversion
- `Cloudflare Pages/Workers` for free tools and SEO landing pages
- `Dev.to`, `Hashnode`, `Medium` for technical tutorials and troubleshooting posts
- `Telegram` for onboarding, segmentation, coupon delivery, and follow-up

Secondary platforms:
- `YouTube` for short demos
- `X` / `LinkedIn` for release distribution and insight snippets
- `Reddit` or technical forums only with value-first answers, never mass posting

- profile creation and management
- start / stop profile automation
- Playwright / Puppeteer / Selenium integrations

## Key Rules To Avoid Spam
- No auto DM
- No mass posting
- No mass comments
- No fake engagement
- Every asset must provide standalone value even if the user never buys
- CTA should appear after value delivery, not before
- Sponsorship should be transparent
- Automation should focus on content ops, tagging, routing, refresh, and repurposing
