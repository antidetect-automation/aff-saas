# Security Policy

## Reporting

Open a private report via GitHub Issues on [aff-saas](https://github.com/antidetect-automation/aff-saas/issues) or discuss responsibly.

Do not post Multilogin account tokens, Telegram bot tokens, or personal data in public issues.

## Scope

- This project’s GitHub Pages hub and Worker bot code in this repository.
- Not Multilogin.com’s platform itself.
