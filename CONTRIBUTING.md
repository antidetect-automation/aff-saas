# Contributing

Thanks for helping antidetect-automation stay useful (not spammy).

## Rules
- Value-first content only — no mass DM / fake engagement ideas
- Always include affiliate disclosure on money pages
- No “undetectable / never ban” claims
- Never commit bot tokens, Multilogin tokens, or proxy credentials

## How we work
1. Edit `site/` in **aff-saas**
2. Push → GitHub Action syncs / Actions Pages deploys `antidetect-automation.github.io`
3. Worker changes live in `worker-bot/` via `wrangler deploy`

## Good PR types
- New compare / troubleshooting pages with unique intent
- Kit improvements (Playwright / Puppeteer / Selenium)
- Bot UX that improves routing `SAAS50` vs `MIN50`

Open an issue first for large ideas: use the Content template.
