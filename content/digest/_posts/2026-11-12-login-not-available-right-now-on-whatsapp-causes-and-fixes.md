# Multilogin + Cloud Phone

We've seen a lot of users struggle with login issues, especially when switching between devices or accounts. It's essential to troubleshoot before trying again to avoid frustration.

- • A proxy server can sometimes interfere with WhatsApp's login process, causing the "Login not available right now" message to appear. Make sure to use a reliable proxy server that doesn't cause any issues.
- • Warm up your cookies by logging in and out of your account on other devices to ensure cookies are set correctly. This can help resolve the issue and prevent the "Login not available right now" message.
- • Cloud Phone vs API/Pro: If you're using Cloud Phone, try switching to API/Pro or vice versa to see if that resolves the issue. This can help determine if the problem lies with your specific setup.
