## Free — $0, five profiles

You get five profiles (cloud mobile or browser), a small premium-proxy bonus, and a short mobile-profile trial window. What you **don’t** get: API access or team seats.

Practical gotcha: if you don’t start any profile for seven days, free profiles can be wiped. Fine for a focused trial week. Bad if you create five shells and ghost them.

Use Free to poke fingerprints and decide if the product fits. Don’t plan a Playwright farm on Free — the API isn’t there.

## Pro — from ~$7.08 / month on yearly

At the 10-profile step we captured **$85 / year** (~**$7.08 / month**). API access starts here. So do the clone/bulk workflows most automation desks actually need. Slider up to more profiles; price scales.

Solo operators and small CDP setups usually land on Pro the moment they outgrow five profiles or need `start` / Launcher automation.
