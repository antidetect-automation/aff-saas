Multilogin ops glossary

Shared vocabulary so deal-desk answers, bot replies, and essays stay consistent.

SAAS50
Affiliate coupon path for Multilogin Antidetect Browser (~50% lifetime via our desk). Stack with yearly when checkout allows — deal.

Affiliate coupon path for Multilogin Cloud Phone — Cloud Phone use-case.
Free plan
Forever-free tier: 5 profiles. No API/team. Idle ~7-day wipe risk — pricing.
Pro plan
Paid tier with API; yearly examples from ~$7.08/mo at 10 profiles (verify checkout).
Business plan
Agency tier: higher profile counts, unlimited seats, higher API limits.
Multilogin X (MLX)
API / automation surface for profiles (Pro+) — API map.
PAM
Profile Access Management — sign-in, refresh, automation tokens. Password often MD5-hashed per Multilogin Postman help.
Launcher
Local Multilogin agent API (e.g. launcher.mlx.yt:45001) to start/stop profiles and return automation ports. App must be running.
automation_type
Query on start: playwright | puppeteer | selenium so the response includes a usable port.
CDP
Chrome DevTools Protocol — how Playwright/Puppeteer attach to a running Mimic profile.
folder_id / profile_id
UUIDs required by Launcher paths; copy from UI/DevTools/Postman.
Profile
One isolated browser identity (fingerprint + cookies + usually one proxy).
Sticky proxy
Exit IP that stays stable across a session / warm period — proxy guide.
Warm-up
Low-risk browsing to build coherent cookies/behavior before high-stakes actions — checklist.
