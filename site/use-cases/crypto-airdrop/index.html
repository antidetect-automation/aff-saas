Crypto browser hygiene

Sane layout

  1. Separate Multilogin profile per high-value wallet UI or research identity.
  2. Do not install every extension into one mega-profile.
  3. Proxy/TZ coherence still matters on web3 frontends — proxy.
  4. Prefer hardware wallets / official apps when the threat model is theft, not “fingerprint theatre.”
