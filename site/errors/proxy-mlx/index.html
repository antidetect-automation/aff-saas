Error desk

Proxy problems

If CDP connects but every page smells wrong, you don’t have a Playwright bug — you have an IP / geo / auth-string problem.

Check these first

  1. Host:port:user:pass pasta — normalize with formatter.
  2. Sticky vs rotating: ads desks usually want sticky for a session.
  3. Timezone/language vs exit country — TZ tool.
  4. Attach proxy on the profile before Launcher start — proxy guide.
  5. Open a geo-check page manually once before automation farms.

API Proxy folder lives in Multilogin’s Postman documenter.

Symptoms teams mislabel as “fingerprint”

  • Login emails say “new device / new location” after every restart — sticky proxy died or rotated.
  • WebRTC or DNS leak shows another country than the profile story — use DNS/WebRTC check.
  • Auth string works in curl but Multilogin UI rejects it — format slip: formatter.
  • CDP is fine; every site rate-limits you — datacenter exit IP, not Playwright.

Ads / MMO note

One money lane ↔ one sticky exit. After changing proxy, expect some cookies to die — cookies. Then re-warm — warmup.
