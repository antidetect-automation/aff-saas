Proxy problems

If CDP connects but every page smells wrong, you don’t have a Playwright bug — you have an IP / geo / auth-string problem.

Check these first

  1. Host:port:user:pass pasta — normalize with formatter.
  2. Sticky vs rotating: ads desks usually want sticky for a session.
  3. Timezone/language vs exit country — TZ tool.
  4. Attach proxy on the profile before Launcher start — proxy guide.
  5. Open a geo-check page manually once before automation farms.
