Error desk

Multilogin X automation errors

When the farm flakes, classify the failure before rewriting half your scripts. Auth, Launcher, attach, and proxy each have their own desk.

Triage order

  1. 401 / sign-in → token desk · auth guide
  2. Start profile fails → Multilogin app running? Pro+ plan? Valid folder_id/profile_id? Official Launcher folder in Postman.
  3. Port returned but connect dies → CDP desk
  4. Sites look “detected” after connect works → usually proxy / geo, not fingerprints.

Plan and core gotchas

  • Free has no API — pricing.
  • Playwright expects Mimic; Stealthfox + Playwright isn’t available per Multilogin docs.
  • Prove the call in Postman before accusing Node — Postman.
