Troubleshooting

Multilogin X automation errors

Fast checks when start-profile, Postman, or Playwright CDP fails. Always verify against current Multilogin docs — endpoints change.

Profile start fails

  • Token expired / wrong workspace
  • Profile UUID typo or wrong folder
  • Local agent / browser core not running
  • Proxy credentials rejected → profile dies at start

Playwright connectOverCDP fails

  • Profile not fully started — wait for debugger port in API response
  • Wrong host (127.0.0.1 vs LAN) when running remote
  • Trying to connect after profile already stopped

401 / unauthorized

  • Regenerate automation token
  • Confirm Authorization header style in latest docs
  • Re-run signin flow in Postman
