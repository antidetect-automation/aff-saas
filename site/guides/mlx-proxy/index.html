Proxies and Multilogin profiles

Most “the antidetect is broken” tickets are proxy stories: wrong country, rotating IP mid-session, or auth string pasta. Fix the lane before you blame WebGL.

Multilogin’s Postman collection has a Proxy folder for attaching and managing proxies on profiles. Paths move — use the official documenter. Below is the operator checklist we give media buyers and automation folks.

Before you scale ads

  1. One profile → one sticky residential/mobile exit when the platform is picky.
  2. Timezone + language inside the profile should not argue with that exit. Snap them with our TZ tool.
  3. Normalize host:port:user:pass with the formatter so Postman/UI paste errors drop.
  4. Start the profile once manually; open a geo-check page; only then wire Playwright.

When automation joins

Start via Launcher with your automation type, then attach CDP (Playwright). If connect works but every site smells datacenter, you don’t have a CDP bug — you have an IP reputation problem. See proxy troubleshooting.
