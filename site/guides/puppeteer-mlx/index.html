Guide

Puppeteer + Multilogin X

Same core loop as Playwright: sign in to Multilogin X → start profile → connect Puppeteer via CDP → automate → stop profile.

Flow

1. Authenticate to Multilogin X API
2. Start profile by UUID
3. Read debugger / CDP endpoint from start response
4. puppeteer.connect({ browserURL or browserWSEndpoint })
5. Run your script
6. Stop profile

Exact host paths change — verify against current Postman collection.

Starter kit

  • puppeteer-mlx-starter
  • Prefer Playwright guide if you are starting greenfield

Common fails

  • Connecting before the profile is fully started
  • Wrong local vs remote debugger URL
  • Proxy geo ≠ profile timezone/language
Browser automation → SAAS50. See automation errors and proxy errors.
