Guide

Multilogin X API authentication

Every automation kit starts here. Exact paths change — always verify against Multilogin’s current Postman / docs.

Pattern

1. Sign in (or automation token flow) → receive access token
2. Store token in env / secret manager — never in git
3. Attach Authorization header on subsequent calls
4. Refresh before expiry if your workspace uses short TTLs
5. Then start profile → CDP attach

Ops rules

  • One secrets source per machine / CI
  • Rotate when teammates leave or tokens leak in logs
  • Prefer Postman to validate auth before coding
