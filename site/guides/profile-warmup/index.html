Profile warm-up checklist

Warming is about consistency, not speed. A cold profile + automated burst is a common failure mode.

  1. Assign a sticky residential/mobile proxy that matches the persona’s geo.
  2. Align timezone, language, and WebRTC/DNS expectations with that geo.
  3. Snapshot fingerprints with WebGL + UA / Client Hints.
  4. Browse a few benign sites manually or with slow automation; persist cookies/sessions.
  5. Only then run your real target workflow — still with human-like pacing.

Do not

  • Reuse one cookie jar across unrelated accounts
  • Rotate proxies mid-session without a freeze-thaw plan
  • Claim or chase “undetectable” setups
