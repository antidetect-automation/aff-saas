Profile warm-up checklist

Warmup is not a magic “trust score.” It’s making sure proxy, timezone, cookies, and human pacing don’t contradict each other the first time a platform sees the lane.

Before login

  1. Sticky proxy attached and geo-checked once inside the profile — proxy · formatter.
  2. Timezone + language snapped to that exit — TZ tool.
  3. Fresh profile storage for that account — no leftover BM cookies — cookies.
  4. Confirm WebGL / UA basics inside the profile if the desk cares — WebGL · UA/CH.

First sessions

  • Browse slowly. Prefer everyday pages before ad manager mega-clicks.
  • Don’t jump countries. Don’t rotate IP mid-login.
  • One profile ≈ one money identity. Parallel junk testing belongs elsewhere.

Free-tier gotcha

Multilogin Free can wipe idle profiles after about seven days. Warm a trial week, decide, then move to Pro if you need API or permanence — pricing.

Automation after warmth

Once the human path looks sane, wire Launcher + Playwright for QA — API map · Playwright. Ads context: Facebook · Google.
