Guide

Playwright + Multilogin X

Pattern: authenticate to Multilogin X API → start profile → connect Playwright to the profile’s CDP endpoint → automate → stop profile.

Prerequisites

  • Multilogin X account + automation token
  • Node.js 18+ and Playwright
  • Proxy assigned to the profile when required by your target

Flow (conceptual)

1. POST /user/signin  (or refresh token flow)
2. POST start profile by UUID
3. Read remote debugger / Selenium port from response
4. playwright.chromium.connectOverCDP(wsOrHttpEndpoint)
5. Run your script
6. Stop profile when done

Exact paths and payloads change with Multilogin’s API revisions — always check their current Postman / docs:

  • MLX API beginners guide
  • Postman collection

Ops tips

  • One profile ≈ one identity; don’t reuse warmed cookies across unrelated accounts
  • Human-like pacing beats faster scripts on strict sites
  • Log profile UUID + proxy lane for every run
